# Recipes

`train_lan_for_model` joins ssms simulation, LANfactory training/export and
development validation. `LANArtifact` exposes the ONNX path, validation evidence,
manifest and (only after all mandatory checks pass) `hssm_model_config`.

See [Train a LAN for an ssms model](../training_a_lan_for_a_new_model.md) for
presets, guards, exact gate thresholds, conditional fixed parameters and limits.
